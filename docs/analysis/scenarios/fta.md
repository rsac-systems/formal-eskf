# Preliminary FTA scope inventory

**Status:** Draft — top-event and contributor candidates only.

[Scope, input baseline, coverage and open questions](README.md) apply to every row.
These are proposed analysis boundaries, not fault trees. Contributor links mean
possible causal relevance, not sufficient causes, AND/OR gates, independence,
minimal cut sets or probabilities. The events can overlap; they are not mutually
exclusive. Consumer tolerances and response intervals remain open in G-01.
FTA-C010 is explicitly an assurance-process event, outside in-flight FHA scope.
