# Preliminary FHA scenario inventory

**Status:** Draft — candidate enumeration only.

[Scope, input baseline, coverage and open questions](README.md) apply to every row.
Each row is a functional failure condition with a possible consumer effect, not
an assigned severity, demonstrated defect or accepted risk. Effects are conditional
on the deployed consumer and mission. Requirements include contributing contracts,
linked through the FMEA candidates; they do not imply that every linked requirement
alone causes the failure. Loss, misleading output and recovery remain distinct.
