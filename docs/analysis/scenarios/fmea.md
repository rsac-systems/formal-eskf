# Preliminary FMEA scenario inventory

**Status:** Draft — candidate enumeration only.

[Scope, input baseline, coverage and open questions](README.md) apply to every row.
The unit is a contract owner or interface in a stated context. Rows are candidate
failure-mode families for later decomposition, not individual test cases or a
source-level FMEA. Failure modes and causes below are hypotheses, not findings
that the implementation violates its requirements. No detection effectiveness,
mitigation credit, criticality or risk score is assigned.
